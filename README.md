# Rajat academic website — 2026 update

This folder is a deployment-ready static website for GitHub Pages.

## Deploy

1. Replace the files in the repository that publishes `https://rajat13-93.github.io/` with the contents of this folder.
2. Keep the HTML, CSS, JavaScript, CV, portrait, favicon, sitemap and all `paper_*`, `pra111_*`, `njp27_*` and `prr8_*` figure assets at the repository root.
3. Commit and push to the branch configured for GitHub Pages (commonly `main`).
4. After GitHub Pages finishes building, verify the home page, CV download, mobile menu and publication filters.

## Content decisions

- The public record is stated as 8 published peer-reviewed papers, 4 first-author, plus 1 accepted PRA paper; 52 citations and h-index 5 as of 21 August 2026.
- Two unready manuscripts were removed because the supplied drafts do not yet support final author lists or universality claims.
- SGPE/SPGPE, dipolar-code and polaron-expertise claims were removed because they are not demonstrated by the supplied publications or code record.
- The unsubmitted MSCA research programme is not described. The research profile is restricted to themes demonstrated by published work.
- Both the institutional email `rajat@post.bgu.ac.il` and personal email `rajat13sep@gmail.com` are available in the contact section.
- The “Research in figures” gallery uses panels from the author manuscripts. Every figure is explained, given accessible alternative text and linked to the version of record. Source and reuse information is available in a compact expandable note below the gallery.
